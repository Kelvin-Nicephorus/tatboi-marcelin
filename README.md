# Tatboi Marcelin – Tattoo Studio Website

## About the Project

Tatboi Marcelin is a tattoo studio website designed to showcase tattoo artwork, artist information, and different tattoo placements.

The purpose of this project is to create an online presence for a tattoo brand and allow visitors to explore its artwork and services.

## Features

- Home page introducing the tattoo brand.
- Artist page showcasing the tattoo artist.
- Gallery page displaying tattoo designs and placements.
- Interactive website navigation.
- Visually appealing design.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Structure

- `index.html` – Homepage
- `artist.html` – Artist page
- `gallery.html` – Tattoo gallery
- CSS files – Website styling
- JavaScript files – Website interactions

Through this project, I improved my understanding of HTML structure, CSS styling, JavaScript functionality, and building multi-page websites.
